# Сегментатор патологий на панорамном снимке
Программа находит на стоматологической панораме области поражений (кариес, апикальные поражения, ретинированные зубы). Она не рисует рамки, а закрашивает пиксели. Номер зуба она не ставит: для этого есть отдельный детектор зубов, а связывать их вместе должен алгоритм агрегации. Здоровые зубы эта модель не ищет: она обучена только на 4 классах болезней.

| Номер  | Цвет  | Название  |
| :--- | :--- | :--- |
| **0** | Черный | **Background** (Фон / здоровые ткани) |
| **1** | Красный| **Impacted** (Ретинированные зубы) |
| **2** | Зелёный | **Caries** (Кариес) |
| **3** | Синий | **Periapical** (Апикальные поражения) |
| **4** | Жёлтый | **Deep Caries** (Глубокий кариес) |

### `scripts/` (Скрипты для запуска)

*   **`prepare_dataset.py`** — Скачивает датасет DENTEX diagnosis. Превращает рамки (bbox) в маски (залитые прямоугольники). Раскладывает снимки по папкам `data/pathology/train|valid|test`.
*   **`prepare_crops.py`** — (Tooth Cropping). Использует YOLO, чтобы найти каждый зуб на панораме, вырезать его и сохранить в `data/pathology_crops/`. Нужен для обучения U-Net на отдельных зубах, чтобы повысить детализацию.
*   **`train.py`** — Главный скрипт для обучения **одной** модели U-Net. Умеет выбирать функцию потерь (`--loss ce`, `--loss dice`, `--loss ce_dice`), размер картинки (`--imgsz`), энкодер и количество эпох. Сохраняет лучшие веса в `runs/segment/`.
*   **`sweep.py`** — Скрипт для перебора параметров. Запускает `train.py` несколько раз с разными настройками (learning rate, энкодер) и собирает таблицу результатов в `report.md`.
*   **`evaluate.py`** — Проверка обученной модели на тестовой выборке. Считает честные метрики Dice и IoU для каждого класса болезней. Сохраняет превью (картинку с наложенной маской) в `runs/predict/pathology_preview/`.
*   **`predict_one.py`** — Запуск модели на одном снимке. Показывает, сколько пикселей занимает каждая болезнь, и сохраняет картинку `runs/predict/one.png` с цветной маской поверх снимка.

---

###  `pathology/` (Модули для приложения)

*   **`segmenter.py`** — Самый важный класс для интеграции (`Segmenter`). Он загружает веса U-Net и делает три вещи:
    1.  `predict_proba` — возвращает вероятности классов.
    2.  `predict` — возвращает цветную маску.
    3.  `predict_lesions` — **разбивает маску на отдельные объекты** и возвращает список словарей (`bbox`, `area`, `mask`, `class_name`). Именно этот метод нужен агрегатору.


---

### `best_model/` (Готовые модели)

*   **`pathology_unet_resnet34.pth`** — Финальные веса U-Net, которые использует приложение (класс `Segmenter`). Сюда копируется победитель из `sweep.py`.

---

###  `data/` (Датасеты, в Git не попадают)

*   **`pathology/`** — Датасет с **целыми** панорамными снимками. Внутри папки `train`, `valid`, `test`. В каждой из них `images` (снимки в jpg) и `masks` (маски в png).
*   **`pathology_crops/`** — Датасет с **вырезанными зубами**. Структура такая же (`train/valid/test` + `images/masks`). Создается скриптом `prepare_crops.py`.

---

###  `weights/` (Промежуточные веса и YOLO)

*   **`yolo_teeth.pt`** — Веса детектора зубов (YOLOv8), взятые из проекта `tooth_detector`. Нужны, чтобы скрипт `prepare_crops.py` мог вырезать зубы.
*   **`candidates/`** — Сюда `sweep.py` сохраняет веса всех вариантов обучения (например, `r34_512_lr3e4.pth`, `mbv2_512_lr1e4.pth`).
*   **`pathology_best.pth`** — Копия лучшей модели (дубликат того, что в `best_model/`).
